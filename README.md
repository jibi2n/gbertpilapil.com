# Gbert Pilapil portfolio

Hello there! This is just a public repository of my personal portfolio website found at gbertpilapil.com

Most of it are just basic stuff and I played around with new frameworks I typically use and don't use. For instance, this is the first time I am using Astro. Pretty cool ngl, and I like how fast it runs.
I am also using Cloudflare to host and deploy this website and its database.

There are a lot of other fluff in the website and I intend to add a lot more easter eggs and such just because I lowkey find it fun, but that will come later.
I plan on iterating this website whenever I have time.

If you check the website, you can also change it in different themes.
First theme is the business card theme, then the main theme for recruiters. I also put an extra Mudkip theme (cause I love mudkip) and an AI theme cause why not.
